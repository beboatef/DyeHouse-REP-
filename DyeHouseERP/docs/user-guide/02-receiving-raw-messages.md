# 2. استلام الخام — الرسائل

> الصلاحية المطلوبة: إنشاء رسالة `raw.receive`، تسجيل الفحص `raw.inspect`، إلغاء رسالة `raw.receipt_cancel`.

الرسالة هي مستند استلام قماش العميل (لحساب الغير). كل رسالة تحمل رقمًا مسلسلًا، والمخزون يُحسب دائمًا من حركة الرسالة — لا يوجد رصيد مخزّن يُعدَّل يدويًا.

## إنشاء رسالة خام جديدة

1. من القائمة افتح **الرسائل** (صفحة `/raw-messages`) ثم اضغط **رسالة جديدة**.
2. اختر **العميل** (صاحب القماش)، و**المخزن** (مخزن خام نشط)، و**تاريخ الاستلام**.
3. أضف سطرًا لكل صنف مستلم: **الصنف**، **اللون**، **الكمية بالكيلو** و/أو **بالمتر** (الوحدتان منفصلتان تمامًا — لا تحويل تلقائي بينهما).
4. راجع الإجماليات ثم اضغط **حفظ**. ستأخذ الرسالة رقمها المسلسل تلقائيًا.

![شاشة إنشاء رسالة: العميل والمخزن والتاريخ وسطور الأصناف بالكيلو والمتر](screenshots/02-raw-message-new.png)

## الفحص: مقبول / مرفوض

1. افتح الرسالة ثم اختر **تسجيل الفحص**.
2. لكل سطر حدّد النتيجة: **مقبول** أو **مرفوض**، واكتب ملاحظة الفحص (سبب الرفض مثلًا).
3. اضغط **حفظ**. السطور المرفوضة لا تُستهلك في أوامر التشغيل.

![شاشة الفحص: نتيجة كل سطر مقبول أو مرفوض مع الملاحظات](screenshots/02-raw-message-inspect.png)

## إلغاء رسالة

1. افتح الرسالة ثم اختر **إلغاء** واكتب **سبب الإلغاء** (إجباري — يُحفظ في سجل التدقيق).
2. لا يمكن إلغاء رسالة استُهلكت سطورها في تشغيل أو تحويل — النظام سيرفض ويخبرك بالسبب.

## ملاحظات مهمة

- **لا يوجد صرف تلقائي (FIFO):** عند صرف الخام لأمر تشغيل ستختار أنت الرسالة والكمية بنفسك كل مرة.
- رسالة مخزنها **موقوف (غير نشط)** لن تُستخدم في أي حركة جديدة — فعّل المخزن أولًا من تعريف المخازن.
- كل الأوزان تُسجَّل كما وردت على الميزان؛ النظام لا يخمّن ولا يحوّل.
