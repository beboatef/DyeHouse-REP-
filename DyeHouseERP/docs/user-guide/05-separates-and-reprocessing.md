# 5. المنفصلات وإعادة التشغيل

> الصلاحية المطلوبة: عرض `production.view`، إعادة التشغيل `production.reprocess`، إعدام (سكراب) `production.scrap`.

المنفصلات هي الإنتاج خارج الدرجة (off-grade): تُفصل عن الدرجة الأولى والثانية وتُعالَج وحدها — إما بإعادة تشغيلها أو بإعدامها.

## مراجعة المنفصلات

1. من القائمة افتح **المنفصلات** (صفحة `/separates`) لرؤية دفعات المنفصلات لكل أمر شغل بالكيلو/المتر.
2. افتح الدفعة لرؤية مصدرها (أي عملية ومرحلة أنتجتها).

![شاشة المنفصلات: الدفعات لكل أمر شغل](screenshots/05-separates-list.png)

## إعادة التشغيل

1. افتح دفعة المنفصلات واضغط **إعادة تشغيل**.
2. اختر **المرحلة التي يبدأ منها** الإصلاح (قد تكون نفس مرحلة العيب أو مرحلة سابقة) واكتب السبب.
3. تُنشأ عملية إنتاج جديدة مرتبطة بالدفعة، وتُتابَع من **متابعة الإنتاج** كأي عملية عادية.
4. **إعادة تشغيل جماعية:** من القائمة حدّد عدة دفعات ثم **إعادة تشغيل المحدد** — تُنشأ عملية واحدة تجمعها.

## الإعدام (سكراب)

1. للدفعة التي لا إصلاح منها اضغط **إعدام** واكتب السبب.
2. الإعدام صلاحية مستقلة (`production.scrap`) لا تُمنح مع صلاحية التعديل — كتابة الخام كفاقد قرار منفصل بذاته.
3. الدفعة المُعدمة تخرج من الأرصدة نهائيًا مع بقاء سجلها للمراجعة.

## ملاحظات مهمة

- لا يجوز إعدام دفعة دخلت بالفعل في عملية إعادة تشغيل جارية.
- كل حركة (إعادة تشغيل / إعدام) تظهر في تتبع المخزون للدفعة.
